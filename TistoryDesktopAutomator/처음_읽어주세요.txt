[티스토리 자동 글쓰기 프로그램 / Windows]

이 프로그램은 티스토리 API를 사용하지 않습니다.
사용자가 로그인한 Google Chrome 창을 실제 마우스/키보드로 조작합니다.

1. 이 ZIP 파일을 모두 압축 해제하세요.
2. Python 3.11 이상 설치 후, 설치.bat을 더블클릭하세요.
3. 실행.bat을 더블클릭하세요.
4. 샘플_게시글.xlsx 에서 제목과 본문을 입력하고 C열(실행)을 Y로 바꾸세요.
5. 크롬에서 티스토리 로그인 -> 글쓰기 URL/글 관리 URL 복사.
6. 프로그램에서 엑셀과 URL을 선택하고 '클릭 위치 설정' 탭에서 6곳을 지정하세요.
7. 먼저 테스트 모드 ON으로 실행하고, draft.png를 열어 입력이 맞는지 확인하세요.
8. 테스트 모드 OFF -> 실제 발행 -> 결과 폴더의 report.csv와 published_*.png 확인.

※ 최초 캘리브레이션은 직접 현재 티스토리 화면의 버튼 위치를 지정해야 합니다.
※ Windows에서 본인 계정으로 실제 발행 테스트는 수행하지 않았습니다.
※ 최종 발행 시도 후 확인이 실패하면 안전을 위해 자동 재시도하지 않습니다.
※ 자세한 사항은 사용설명서.md를 확인하세요.

[자주 묻는 질문]
- Python 없이 EXE만 실행하고 싶으면 Windows에서 EXE만들기.bat을 실행하세요.
- 글이 작성되지 않고 멈추면 클릭 좌표와 Chrome 화면 배율(100%)을 확인하세요.
- 글 관리에서 등록 여부가 불분명하면 직접 확인한 후 다음 글을 처리하세요.
